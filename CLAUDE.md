## Цель

Пользователь хочет научиться строить простую LLM с нуля. Исходная идея и пример
кода (bigram-модель на PyTorch) лежат в `file.txt`: 6 шагов — подготовка текста,
перевод в числа, примеры, архитектура, обучение, генерация. Общение на русском.

## Окружение

- Windows 11, PowerShell.
- Python по умолчанию 3.15: для него нет PyTorch. Поэтому всё запускается через
  **`py -3.12`**, там установлены torch 2.15.0+cpu и numpy 2.5.5
  (numpy поставили, чтобы убрать предупреждение `Failed to initialize NumPy`).
- Видеокарты нет, обучение на CPU.

## Что умеет `tiny_llm.py`

- Две архитектуры (`--model`):
  - `bigram` (по умолчанию): таблица vocab×vocab, block 16, lr 0.05, ~17 тыс. параметров, обучение ~5 с;
  - `gpt`: мини-трансформер в стиле nanoGPT, n_embd 128, 4 головы, 4 слоя, block 128,
    dropout 0.1, lr 1e-3, ~840 тыс. параметров, ~0,27 с/шаг, 3000 шагов ≈ 15 мин.
- `--data` принимает несколько файлов, папок (все `.txt` внутри) или масок (`*.txt`).
  Маски раскрывает сам скрипт, PowerShell этого не делает.
- Читает UTF-8 (в том числе с BOM) с запасным вариантом cp1251; убирает nbsp, `\r\n`,
  лишние пробелы и пустые строки.
- Редкие символы выбрасываются: порог `max(1, всего_символов // 30000)`.
- Проверочная часть (val) — последние 10% **каждого** файла; файлы склеиваются через `\n\n`.
- Перед обучением печатаются доли файлов в процентах.
- Модель сохраняется в `tiny_llm_<имя>_<модель>.pt` как словарь
  `{model, chars, model_type, files}`. Генерации тексты не нужны, словарь
  символов берётся из файла модели. Старый формат (только веса) тоже загружается.
- Как получается `<имя>`: `--name`, иначе имя папки (если одна папка), иначе имя
  файла (один файл), иначе имена файлов через `+` (обрезается до 80 символов).
  - В `--name` можно указать и полное имя файла (`tiny_llm_X_gpt.pt` или
    `tiny_llm_X_gpt`): префикс и суффикс отрезаются, `--model` берётся из имени.
- `--generate-only` открывает ровно вычисленный файл, а не «последний» в папке.
  Если файла нет, печатает список имеющихся моделей.
- Повторное обучение с тем же именем и типом **перезаписывает** модель.
  Дообучения (`--resume`) нет.
- `--steps` (по умолчанию 3000, `0` — без обучения), `--prompt` («Князь Андрей»),
  `--length` (500), `--temperature` (0.8).
- Подробная справка на русском (`--help`): описание, все параметры, примеры по группам.
  argparse разбирается до `import torch`, поэтому справка показывается мгновенно.
- Вывод принудительно в UTF-8, чтобы не было ошибок при перенаправлении (`> out.txt`).
- Понятные ошибки: файл не найден (со ссылкой на README), слишком мало текста,
  нет модели.
