# Tiny LLM — языковая модель с нуля

Учебный проект: маленькая символьная языковая модель на PyTorch в одном файле.
Модель учится на любом тексте (например, на «Войне и мире»), а потом
дописывает текст в его стиле.

Модель не «умная», но на ней хорошо видно, как устроены настоящие LLM
вроде GPT: токенизация, обучение предсказывать следующий токен, механизм
внимания и генерация.

```
Князь Андрей две того же совершил солдат. Были они гостьев все себя.
В сердце, он все наших слабеясь их прилично. — Уже бы казалось.
— Не прислушивался во всей перенгли так! — сказал Пьер и опулся ее было всё мой...
```
<sub>Мини-GPT (около 840 тыс. параметров), обучение на процессоре около 15 минут.</sub>

## Возможности

- Две архитектуры для сравнения:
  - **bigram**: видит только один предыдущий символ, обучается за секунды;
  - **gpt**: мини-трансформер с самовниманием, видит 128 предыдущих символов.
- Обучение на одном или нескольких `.txt` файлах, на папке или по маске (`*.txt`).
- Тексты читаются в кодировке UTF-8 или Windows-1251.
- Модель сохраняется вместе со словарём символов, поэтому для генерации тексты не нужны.
- Подробная справка на русском: `python tiny_llm.py --help`.

## Установка

Нужен Python 3.9–3.13 (проверено на 3.12) и PyTorch.

```bash
git clone <url-репозитория>
cd <папка-репозитория>
pip install -r requirements.txt
```

Видеокарта не нужна. Если хотите поставить облегчённую сборку PyTorch только для процессора:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install numpy
```

> **Windows:** если установлено несколько версий Python, запускайте через
> нужную версию, например `py -3.12 tiny_llm.py`. Для самых новых версий Python
> PyTorch может ещё не выпустить сборку.

## Данные

В репозиторий уже входит `voina-i-mir.txt` — «Война и мир» Л. Н. Толстого
(около 3,6 млн символов, UTF-8). Скрипт берёт его по умолчанию, поэтому
`python tiny_llm.py` работает сразу после клонирования.

Источник: электронное издание Полного собрания сочинений Л. Н. Толстого
(ГИХЛ, 1937–1940), проект «Весь Толстой в один клик», [tolstoy.ru](https://tolstoy.ru).
Роман находится в общественном достоянии.

### Свой текст

Подойдёт любой `.txt` файл, его путь передаётся через `--data`.

- Объём: от нескольких сотен тысяч символов, лучше несколько мегабайт.
  На маленьком тексте модель просто заучит его наизусть.
- Чем однороднее текст (один автор, один жанр), тем лучше результат.
- `.docx` и `.pdf` сначала сохраните как обычный текст (`.txt`).
- Уберите служебный «мусор» вроде шапок сайтов и оглавлений, иначе модель выучит и его.
- Свои тексты в репозиторий не попадут: `.gitignore` исключает все `.txt`,
  кроме `voina-i-mir.txt` и `requirements.txt`.

> Используйте тексты, на которые у вас есть права, например книги в
> общественном достоянии.

## Быстрый старт

```bash
# 1. Bigram-модель: обучение примерно за 5 секунд
python tiny_llm.py

# 2. Мини-GPT: около 15 минут на процессоре, текст заметно лучше
python tiny_llm.py --model gpt

# 3. Генерация уже обученной моделью, без повторного обучения
python tiny_llm.py --model gpt --generate-only --prompt "Наташа" --length 1000
```

Во время обучения печатается ошибка (loss) на обучающей (`train`) и проверочной (`val`) части текста:

```
шаг   250 | ошибка train 2.576 | val 2.763 | 71 c
```

Чем меньше ошибка, тем лучше. Если `train` падает, а `val` растёт, модель
заучивает текст, а не учится: нужно больше данных.

## Примеры

```bash
# Свой текст
python tiny_llm.py --data skazki.txt --model gpt --prompt "Жил-был"

# Несколько файлов в одной модели (с коротким именем модели)
python tiny_llm.py --data voina-i-mir.txt anna-karenina.txt --name tolstoy --model gpt

# Все .txt из папки или по маске
python tiny_llm.py --data "C:\Тексты\Толстой" --model gpt
python tiny_llm.py --data "texts/*.txt" --name all --model gpt

# Учить дольше
python tiny_llm.py --model gpt --steps 10000

# Генерация с другой «смелостью»
python tiny_llm.py --name tolstoy --model gpt --generate-only --temperature 0.5
python tiny_llm.py --name tiny_llm_tolstoy_gpt.pt --generate-only --temperature 1.3
```

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--data ФАЙЛ ...` | `voina-i-mir.txt` | Один или несколько `.txt` файлов, папок или масок |
| `--name ИМЯ` | по имени данных | Имя модели. Можно указать и полное имя файла `tiny_llm_..._gpt.pt` |
| `--model` | `bigram` | Архитектура: `bigram` или `gpt` |
| `--steps N` | `3000` | Сколько шагов обучения |
| `--prompt ТЕКСТ` | `Князь Андрей` | Начало текста для генерации |
| `--length N` | `500` | Сколько символов сгенерировать |
| `--temperature T` | `0.8` | Меньше 1: осторожнее и однообразнее, больше 1: смелее и безумнее |
| `--generate-only` | — | Не обучать, а загрузить сохранённую модель |

## Где хранятся модели

Обученная модель сохраняется рядом со скриптом в файл `tiny_llm_<имя>_<модель>.pt`.
В нём лежат веса, словарь символов и список файлов, на которых модель обучалась.

`<имя>` берётся так:
- из `--name`, если он указан;
- иначе из `--data`: имя файла, имя папки или имена файлов через `+`.

При `--generate-only` скрипт открывает **ровно этот** файл, а не «последнюю» модель
из папки. Тип модели по умолчанию `bigram`, поэтому для мини-GPT добавляйте
`--model gpt` или указывайте полное имя файла в `--name`.

Повторное обучение с тем же именем и типом модели перезаписывает файл.

## Как это работает

Скрипт по шагам повторяет путь любой языковой модели:

1. **Подготовка текста.** Чтение файлов, очистка лишних пробелов и редких символов.
2. **Токенизация.** Каждый символ получает номер (словарь из 100–150 символов).
3. **Примеры.** Случайные кусочки текста: модель по символам `x` угадывает
   те же символы, сдвинутые на один (`y`). Из каждого файла 90% идёт в обучение
   и 10% в проверку.
4. **Архитектура.**
   - `bigram`: одна таблица «какой символ идёт после текущего»;
   - `gpt`: эмбеддинги символов и позиций, затем 4 блока трансформера
     (4 головы самовнимания + MLP, LayerNorm, residual-связи).
     Параметры: `n_embd=128`, контекст 128 символов.
5. **Обучение.** Перекрёстная энтропия и оптимизатор AdamW.
6. **Генерация.** Модель предсказывает распределение следующего символа,
   выбирает символ с учётом `temperature`, добавляет его к тексту и повторяет.

Архитектура мини-GPT основана на идеях
[nanoGPT](https://github.com/karpathy/nanoGPT) Андрея Карпатого.

## Что можно попробовать дальше

- Увеличить модель (`n_embd`, `n_layer`, `block_size` в разделе «Гиперпараметры» скрипта) и учить дольше.
- Токенизировать по словам или частям слов (BPE) вместо символов.
- Обучать на видеокарте или в Google Colab: скрипт сам использует CUDA, если она есть.
- Дообучать уже сохранённую модель вместо обучения с нуля.
